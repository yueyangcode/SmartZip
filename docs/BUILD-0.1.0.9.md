后端烟雾测试对五格式多选核验解压数据内容，不代表所有格式都保留原始 Unicode 内部文件名；本次 TAR 类兼容格式样本出现非 BMP 字符替代名。ZIP 原生启动器用例另行核验了原始中文/emoji 文件名与内容。

原生 DLL 构建仍有既有的两条导出函数重复声明警告，不影响编译；不以此推断 Explorer 已通过稳定性验收。
