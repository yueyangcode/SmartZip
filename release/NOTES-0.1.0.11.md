# SmartZip 0.1.0.11 开发测试版

适用于 Windows 11 x64（Build 22621 或更新）。这是测试签名版本，仍处于发布草稿阶段，不是正式发行版，不触发软件更新提示。

## 功能与变更

- 在 Windows 11 现代右键菜单提供「智能解压」。内置独立 7-Zip 后端，无需另装 WinRAR/7-Zip，不替换现有压缩软件或旧式菜单。
- 中文安装向导；选择父目录后自动补齐 SmartZip 文件夹。支持单选、多选及中文、空格、特殊字符路径。
- 包含 0.1.0.10 新增的更新确认、下载校验和后台安装逻辑。完整远程更新链仍待验收；草稿及预发布不会触发更新。
- 修复安装验证主动加载右键 COM 扩展、可能占用旧 Package 的问题。安装、提交和回滚增加 Package 健康校验；版本号恢复但仍需修复的 Package 不再算回滚成功。
- 区分占用与回滚失败的中文提示。Windows 拒绝恢复时保留恢复资料，不强制结束 Explorer/解压任务，不通过延迟注册报告成功。

## 安装与升级限制

软件按当前用户安装。测试版首次安装需要用户同意专用测试证书，只有证书助手请求管理员权限，将公钥导入 `LocalMachine\TrustedPeople`；不进入 Root，不向信任库导入私钥。签名者为 `CN=SmartZip Modern Evaluation`，证书指纹为 `A1709CED9DB02150E2FB40CE6496BD1938D89195`。新电脑可能显示安全或信任提示，不应关闭 Windows 安全检查。

支持从健康且身份完整的 0.1.0.8 或更新旧版本进行同目录、同证书升级。已经安装 0.1.0.11 时无需重复安装；同版安装、降级和目录迁移会被拒绝。测试证书到正式证书的迁移尚不支持自动升级。

安装前发现旧 Package 处于 Modified/NeedsRemediation 等异常状态时会停止。请保留日志另行诊断，不手工删除文件、补注册或改证书。真实程序占用仍可能阻止 Windows 更新 Package。
