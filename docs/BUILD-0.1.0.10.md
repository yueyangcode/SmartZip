真实「正式 Release → 确认 → 下载 → 验签 → 静默升级 → 最终注册验证」仍需测试环境验收。本轮没有通过发布虚假正式 Release 来触发测试，也没有执行远程安装包。当前测试证书不能自动切换到另一张正式证书。
