# SmartZip 0.1.0.9 升级开发测试版

这是发布草稿，不是正式版。使用自签名开发证书；首次安装需明确同意项目证书信任，证书仅进入 LocalMachine\TrustedPeople，不进入 Root。

## 本次变化

- 从身份完整的 0.1.0.8 开始支持同目录覆盖升级，自动沿用原安装位置。
- 新版放入独立版本目录；保留旧版和用户配置。
- 失败时先恢复旧 Package，再恢复产品状态、卸载文件及快捷方式。恢复失败保留备份，不继续删除依赖。
- 升级保留原证书所有权，不重复建立测试信任；正式签名构建分支不包含证书提升助手。
- 中文目录页直接显示自动补全后的 SmartZip 路径，避免覆盖无有效安装身份的同名目录。
- 稳定版更新检查仍只打开 GitHub 正式发布页面，不自动下载或执行安装包。

## 验证边界

0.1.0.8 的本机及第二台 Windows 11 测试为用户反馈通过。0.1.0.9 已运行代码层策略、序列化、失败顺序、跨进程管道及工作区后端解压测试，但真实 Windows 覆盖升级、Package 降级恢复、升级后卸载尚待验收。详见仓库中的 `docs/BUILD-0.1.0.9.md`。
不要在重要机器上用故障注入版本测试。不要把本草稿标成正式版本，或直接提交到公共 WinGet。

## 兼容与限制

- Windows 11 x64，系统版本至少 22621；新版 Context menu 设置页是否存在取决于系统本身。
- 内含可工作的 7-Zip 后端；无需另装 WinRAR 或 7-Zip，也不修改它们。
- 只支持同目录、同签名证书升级，不支持升级中迁移目录、跨签名切换、同版重装或降级。
- 旧版本目录暂保留到正常卸载；用户配置保留在原 UserData 目录。
- 正式签名材料尚未提供，公共 WinGet 尚未提交。

第三方许可及对应源码随安装包提供。安装前请核对附带的 SHA256SUMS.txt。
