# SmartZip 0.1.0.15 开发测试版

**开发测试版预发布说明。** 本版已完成沙盒内 `.14 → .15` 覆盖升级核验，用户确认新图标及 ZIP 解压正常；正式发行所需验证和可信签名仍未完成。

适用于 Windows 11 x64（Build 22621 或更新），不是稳定版，不提供 macOS、Linux 或 ARM64 安装包。

## 这次更新

- 换用新的 Win11 风格图标，统一安装向导、程序、开始菜单和「智能解压」右键图标；支持透明背景及多档像素尺寸。
- 继续内置独立的 7-Zip 解压后端，无需另装 WinRAR 或 7-Zip，不修改其他压缩软件和旧式菜单。
- 保留中文安装向导、父目录自动补齐 SmartZip 文件夹、中文/空格/特殊字符路径和多选支持。
- 相比 0.1.0.14，本版没有改变解压、安装权限、升级回滚和更新器逻辑，也没有新增运行依赖。
